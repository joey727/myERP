How to Install

Web App / PWA Steps (Add to Home Screen)
1 Tap the "Launch myERP Web App" button above.
2 Once the web app loads, tap the browser's Share button (iOS Safari) or the **Menu** button (Android Chrome).
3 Select "Add to Home Screen" from the options.
4 Launch myERP directly from your Home Screen for a standalone, full-screen, offline-capable experience!
iOS Native Installation Steps
1 Tap the "Install on iOS Device" button above in Safari browser.
2 A system alert will ask if you want to install myERP. Click Install and check your Home Screen for the loading app.
3 If you see an "Untrusted Developer" dialog when opening the app, go to Settings -> General -> VPN & Device Management.
4 Tap on your Enterprise or Ad Hoc developer profile (under "Developer App" or "Enterprise App") and tap Trust.
Android Sideloading Steps
1 Tap the "Download Android APK" button above.
2 If prompted by your browser, tap "Download Anyway" to save the `.apk` file.
3 Once downloaded, open the file from your downloads list. If you get a warning about installing unknown apps, tap Settings.
4 Toggle "Allow from this source" on, then return and tap Install.
