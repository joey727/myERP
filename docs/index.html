First run

From empty counter to first sale in minutes.

A short guided setup creates the business, the receipt details and the owner login. No account, no email verification and no internet required.

  1. 1

    Name the business

    Shop name and type — retail, provision store, pharmacy, food, boutique or spare parts.

  2. 2

    Add receipt details

    Phone, email, address, tax ID and a receipt footer. All optional, all editable later.

  3. 3

    Create the owner

    A name and a 4-digit PIN. Managers and cashiers can be added once the till is open.

  4. 4

    Open the till

    Add products, set low-stock lines and make the first sale. Setup takes about two minutes.

Developer quick start

Requires Node.js 22 and npm. The web export is a static site; no server or database service is needed.

# clone and install
git clone https://github.com/joey727/myERP.git
cd myERP
npm install

# run the web app locally
npm run web

# build the static web export
npm run build:web

# run on a device or simulator
npm run android
npm run ios
Good to know

Straight answers.

Does myERP really work offline?

Yes. Products, sales, staff, customers and reports are stored in a local database on the device. The Android app works offline from the first launch. The web app downloads once, then keeps working without a connection.

Where is my data stored?

On your device. There is no cloud account and no server holding your shop data. The web app and the Android app use separate local stores, and every browser or device keeps its own copy. Export a CSV backup from Backup and export whenever you need one. The only thing that leaves a device is an anonymous count of app opens, with no shop data, account or identifier.

Can I use the same shop on more than one device?

Not automatically. Each device holds its own local data, so myERP is best used as the till on one main device. If you need records on another device, export the CSV and keep it as a record. Live multi-device sync is not part of the current release.

Do I need an account or a subscription?

No. There is no sign-up, no email verification and no monthly fee. Staff sign in with a local 4-digit PIN. myERP is free and open source under the MIT licence.

How do updates work?

The web app updates when you reload it. For Android, download and install the latest APK over the existing app; the local database is kept. Your products, sales and staff stay in place.

Ready to open the till?
